Automate the work. Keep judgement where it belongs.

A support agent should not be judged only by whether it can draft an answer. It needs an explicit action policy: some requests can receive a low-risk response, some need approval, and some must always go to a person.

03 / Inspect the implementation

Architecture and policy gates

Request intake→Intent classification→Risk policy→Confidence threshold→Answer or human review

Customer/business problem: repetitive support work consumes agent time, but unbounded automation can make costly mistakes. Explicit routing makes the trade-off inspectable. A production system would require authenticated tools, least-privilege access, audit logs, PII controls, monitoring, and human-approved action execution.
